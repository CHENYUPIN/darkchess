# 暗棋 Banqi — 單檔網頁版

純前端、零依賴的暗棋（Chinese Dark Chess）網頁遊戲，整個遊戲就是一個 `index.html`，沒有建置步驟，也不需要伺服器。

## 功能

- **雙人同機**／**挑戰電腦**兩種模式
- 電腦四種強度：簡單、普通、困難、大師（困難與大師會多想一步）
- 開局前先擲骰決定先後手
- 完整暗棋規則：翻子定色、兵卒吃將帥、炮隔子跳吃
- **禁止長捉**：同一枚棋子連續三個迴圈追捉同一目標，第三次重複視為禁止著法
- 電腦局勢無望時會自動投降
- **悔棋**（挑戰電腦模式）：一次撤回你上一手與電腦的回應，並正確把已翻開的暗子蓋回去
- 手機版面、觸控操作、音效（可靜音）

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。

### 部署到 GitHub Pages

1. 把本專案推到 GitHub repo
2. 到 **Settings → Pages**
3. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`
4. 儲存後約一分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`

## 說明

- 字體透過 Google Fonts 載入；離線時會自動退回系統字體，不影響遊玩。
- 所有邏輯都在 `index.html` 內的單一 `<script>` 區塊。
